## 截图规范

### 命名规则
- 格式：`序号-功能描述.png`
- 示例：`03-knowledge-base.png`、`04-agent-tools.png`

### 截图要求
1. **尺寸统一**：桌面端建议 1920x1080 或 1440x900，移动端建议 375x812
2. **内容完整**：展示完整功能界面，包含标题、内容、操作区
3. **状态正常**：确保界面无报错、无加载中状态
4. **数据真实**：使用真实的对话内容和功能演示，避免占位符
5. **主题一致**：默认使用浅色主题，如需展示深色主题请单独标注
